
# Student & Course Management System 

A comprehensive web application built with Python and Flask. This project serves as a Capstone Project, demonstrating full-stack development skills including user authentication, CRUD operations, RESTful APIs, and unit testing.

## Features
* **User Authentication:** Secure Sign Up, Log In, and Log Out functionality.
* **Student Management:** Create, Read, Update, and Delete (CRUD) student records.
* **Course Management:** Create and View courses.
* **REST API:** Endpoints to fetch student data in JSON format.
* **Automated Testing:** Unit tests implemented for core routes and functionalities.
* **Database:** SQLite database integrated with SQLAlchemy (ORM).
* **Cloud Deployment:** Fully deployed and hosted on Render.

##  Tech Stack
* **Backend:** Python, Flask
* **Database:** SQLite, Flask-SQLAlchemy
* **Testing:** Python `unittest`
